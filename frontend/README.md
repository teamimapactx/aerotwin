# AeroTwin Mission Control
MALE UAV Piston Powerplant Digital Twin, Real-Time Magneto & Ignition Telemetry, What-If Simulation, and PDF Diagnostic Reporting.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the local development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

Built with React 19, TypeScript, Vite, and Tailwind CSS.
